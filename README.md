# Plataforma Radical: landing page

Página de apresentação do sistema de gestão de acampamentos: site de inscrição, área do equipante e painel da coordenação.

Página estática (HTML, CSS e JS, sem build), publicada pelo GitHub Pages a partir da branch `main`.

As telas em `img/` são capturas reais do sistema, com nomes, e-mails, telefones, CPFs e fotos de pessoas trocados por dados fictícios ou desfocados.
